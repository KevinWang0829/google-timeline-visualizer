隱私說明

更新日期：2026 年 8 月 20 日

重點：你選擇的 Timeline JSON、座標、日期、標題、影片畫面與 MP4 都只在目前瀏覽器分頁中處理，不會上傳到本站或應用程式伺服器。

Timeline 資料

網站只讀取你主動選擇的 JSON 檔，不會要求 Google 帳號、裝置位置、聯絡人、相片或廣泛檔案權限。重新整理或關閉分頁後，載入中的 Timeline 資料會從頁面記憶體移除。

地圖請求

只有在你勾選同意後，網站才會向 CARTO 請求 OpenStreetMap 地圖圖磚。請求包含縮放層級與地圖格座標，以及 IP 位址、瀏覽器資訊等一般網路資料；這可能讓 CARTO 推知你所瀏覽的地理區域。網站不會把完整路線、JSON、標題或影片傳給 CARTO。

儲存與分析

網站不把 Timeline 寫入 localStorage、IndexedDB 或服務工作者快取，也不加入分析追蹤或遠端錯誤記錄。服務工作者只可能快取網站本身的靜態檔案。產生的影片在目前分頁以暫時 Blob URL 提供下載或分享。

GitHub Pages

網站由 GitHub Pages 託管。一般網頁請求仍會向 GitHub 暴露 IP 位址、瀏覽器資訊、請求時間等標準網路資料；詳情請參閱 GitHub 隱私權聲明。
