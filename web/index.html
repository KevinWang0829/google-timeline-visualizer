如何匯出 Timeline
  1. 開啟 Google 地圖，點選個人資料相片。
  2. 前往「設定」→「個人內容」。
  3. 選擇「匯出 Timeline 資料」。
  4. 回到這裡選取匯出的 JSON 檔。
